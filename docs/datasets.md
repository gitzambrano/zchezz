# Training Datasets and Provenance Catalog

This document defines the dataset conventions, schema rules, and the complete catalog of training datasets for Zchezz.

## 1. Nomenclature and Conventions

Zchezz uses a closed vocabulary for evaluation and target values. Every score is White-relative.

| Term | Meaning | Range | Persistence |
|---|---|---|---|
| `cp` | Position evaluation in centipawns | Integer, White-relative | Stored in dataset column `cp` |
| `result` | Actual game outcome | `0.0` (Black won), `0.5` (Draw), `1.0` (White won) | Stored in dataset column `result` |
| `wdl` | `sigmoid(cp / 320)` win/draw/loss probability | Float in `0.0..1.0`, White-relative | Computed at training time; never stored |
| `target` | Blended training target: `lambda * result + (1 - lambda) * wdl` | Float in `0.0..1.0`, White-relative | Computed dynamically by trainer |

### Governing Rules

1. `wdl` is never stored as a column. It is an exact mathematical function of `cp`. Storing both permits values to diverge.
2. `lambda` blending requires both `cp` and `result`. If a dataset contains only `cp`, `lambda` is inert.
3. `result` uses only `0.0`, `0.5`, or `1.0`. Blanks remain missing; they are not imputed as draws.
4. Scale constant `320` matches `CP_TO_WDL_T` in training and `_nnL3B * 320.0f` in C runtime evaluation.

### Dataset Directory Naming Standard

Directory names append tags in this canonical order:
`<source>_<core>_<cp>_<evaluator>_<res>_<endgames>_<filter>_<data>`

| Tag | Meaning |
|---|---|
| `_cp` | Contains an evaluation column (`cp`) |
| `_res` | Contains a game result column (`result`) |
| `_filter` | Filtered for quiet (non-tactical) positions |
| `_raw` | Unfiltered, raw source data |
| `_endgames` | Endgame positions only |
| `_data<YYYYMMDD>` | Generation date with four-digit year |
| `_sf<budget>` | Evaluated by Stockfish with node budget (e.g. `sf50k`, `sf100k`) |
| `_sfd<depth>` | Evaluated by Stockfish with depth budget (e.g. `sfd12`, `sfd14`) |
| `_sfdb` | Stockfish evaluations bundled directly with upstream database |
| `_zchezz` | Evaluated by Zchezz search during self-play |
| `selfplay_` | Generated by self-play games of Zchezz |
| `synthetic_endgame_` | Procedurally generated positions without played games |
