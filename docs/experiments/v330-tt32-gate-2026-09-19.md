# v3.30 TT32-key gate — 2026-09-19

## Hypothesis

Increase the transposition-table verification key from 16 to 32 bits while keeping the
same configured Hash budget. The candidate also changes the physical cluster from
3 x 10-byte entries in 32 bytes to 5 x 12-byte entries in 64 bytes. No NNUE weights,
evaluation features, or training data change.

Historical v3.30 remains immutable. This gate only decides the development baseline.

## Prior screen

The original 32-game 80 ms/move screen on `exp/v330-structural-rerun` produced:

- TT32-key vs v3.30: **9W / 20D / 3L**, 59.375%, **+65.9 Elo** (reported CI about +/-72.7).
- perft: 37/37.
- extended UCI: 47/47 assertions, 2 skipped.
- screen H2H NPS: effectively unchanged.

Structural controls from the same run:

- corr2 vs v3.30: **4W / 18D / 10L**, about **-65.9 Elo**.
- TT32-key + corr2 vs v3.30: **8W / 18D / 6L**, about **+21.7 Elo**.

Therefore the large gate tests TT32-key alone.

## Validation

Run: `35445994838`, branch: `exp/v330-tt32-gate`.

Pre-H2H validation passed:

- candidate NNUE file is byte-identical to v3.30 (`cmp`);
- perft: 37/37;
- extended UCI: 47/47 assertions, 2 skipped;
- v3.30 bench: 10,644,878 nodes, 1,527,242 NPS;
- TT32-key bench: 10,994,369 nodes, 1,528,056 NPS;
- throughput ratio: approximately **1.00053** (+0.05% NPS).

The fixed-depth node count differs because the TT layout changes the search tree. Throughput is
effectively neutral.

## Large gate design

- 400 games = 200 paired openings.
- 8 independent shards x 25 opening pairs.
- deterministic shuffled opening order with disjoint offsets.
- pinned Stockfish UHO book: `UHO_4060_v4.epd` at books SHA
  `65815ccdbc7727cd4f6aee252ba8f67fb740e92f`.
- 80 ms/move, Threads=1, Hash=64 MB, Syzygy disabled.
- max 260 plies after the opening.
- candidate is always evaluated against unmodified v3.30.
- per-pair outcomes are retained and aggregated with a 50,000-resample paired bootstrap.

Promotion rule for the development baseline:

1. no functional regression;
2. no material throughput regression;
3. positive point Elo;
4. paired-bootstrap 95% lower bound above 0 Elo (equivalently strong evidence that the gain is positive).

Short screens remain triage only. Historical versions/tags are never rewritten.

## Result

Run `35445994838` completed successfully.

- 400 games / 200 paired openings.
- TT32-key: **115W / 182D / 103L**.
- score: **51.5%**.
- point estimate: **+10.43 Elo**.
- paired-bootstrap 95% CI: **[-13.90, +34.86] Elo**.
- paired-bootstrap LOS: **78.87%**.
- H2H NPS ratio: **0.99998** (effectively identical).
- average depth: 14.931 vs 14.857.

The result does **not** meet the promotion rule because the 95% lower bound is below zero.
TT32-key is therefore **not promoted** to the development baseline. The 32-game +65.9 Elo
screen was a sampling fluctuation at the precision required for promotion.
